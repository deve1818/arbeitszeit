# Arbeitszeit

Einfache Web-App zur Arbeitszeiterfassung fürs iPhone: einstempeln, Pausen, Einträge nachtragen,
Stunden pro Woche und Monat zusammenrechnen, CSV-Export und Backup.

Läuft offline. Alle Daten bleiben nur auf dem Gerät (localStorage) – es gibt keinen Server und kein Konto.

**Installation auf dem iPhone:** Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
